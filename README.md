# Convert_files_obsidian_to_logseq

Convert files obsidian to logseq

## Convertion files

Convert files following structure of files '![[file_name.extension|size]]' or '![[file_name.extension]]' from *Obsidian* to '\!\[file_name\]\('file_path/file_name.extension'\)' *Logseq*.

## How to use

In the configuration file 'config.json' put the path of the Obsidian you want to convert in 'your_path'.

> [!NOTE]
> Do you need rename 'config.json.template' to 'config.json'.
